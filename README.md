# Course Management System

Application de gestion de cours développée dans le cadre d'un stage.

## Stack technique

- **Backend** : Java 21, Spring Boot, MariaDB
- **Frontend** : Angular 18
- **Autres** : JPA/Hibernate, JPQL (requêtes statistiques personnalisées)

## Fonctionnalités

- CRUD complet sur les entités du domaine
- Gestion des erreurs et validation des données
- Endpoints métier (logique applicative avancée)
- Statistiques via requêtes JPQL sur mesure
- Documentation API (collection Postman)

## Architecture

Refactorisation UML v2 réalisée pour clarifier les relations entre entités et
améliorer la maintenabilité du modèle de données.

## Installation

Voir le guide d'installation (Word) fourni dans le dépôt pour la configuration
de l'environnement, de la base de données et le lancement des serveurs
backend/frontend.
